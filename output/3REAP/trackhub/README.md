    ├── trackDb.txt

## Tracks

| Section | Source set | Default |
|---|---|---|
| PolyA_DB v4.1 | `hg38.PAS.v4.1.bb` | pack |
| PAS composites (4 conditions × plus/mi) | `PASS_bw_LAP24_PAS` | plus full, mi hide |
| PASS-read overlays (4 conditions × plus/mi) | `PASS_bw_LAP24` | plus full, mi hide |
| PASS reads per-rep matrix | `PASS_bw_LAP24` | hide |
| All aligned reads | `mapped_read` | dense |
| PASS LAPs | `PASS_bw_LAP24_positon` | hide |

Colours: control/untreated = greys, control/TGFB = oranges, CFIm25/untreated = blues,
CFIm25/TGFB = reds (three shades = three replicates).

## Deploy

```bash
# 1. put the bigWig folders next to trackDb.txt
cp -r /compbio/data/ClaireMoore/cmoore_021.CFIm25_OE/processed/3_REAP/06_bigwig/* hg38/

# 2. upload
scp -i jenkinsaccess_key_pair.pem hub.txt genomes.txt \
    ec2-user@ec2-3-83-106-170.compute-1.amazonaws.com:/var/www/html/cmoore_021/
cd hg38
scp -i jenkinsaccess_key_pair.pem -r ./* \
    ec2-user@ec2-3-83-106-170.compute-1.amazonaws.com:/var/www/html/cmoore_021/hg38/

# 3. optional check (UCSC kent tools)
hubCheck http://3.83.106.170/cmoore_021/hub.txt
```
